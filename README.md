# QA Automation Case Study – WorkFlow Pro

## Overview
This repository contains my solution for a QA Automation case study
focused on testing a multi-tenant B2B SaaS platform.

## Tech Stack
- Python
- Pytest
- Playwright
- API Testing (conceptual)

## Repository Structure
- test-plan/: Test strategy and scenarios
- automation/ui/: UI automation samples
- automation/api/: API test samples
- test-data/: Sample test data
- docs/: Case study explanation

## Notes
- This is a conceptual implementation for an intern-level assessment.
- Tests are written to demonstrate testing approach and structure.
- Focus is on reliability, scalability, and CI/CD readiness.
